HighWire Test Suite

Element and CSS coverage tests, grouped by category. Each page exercises the features HighWire's parser and renderer actually support (from token.h / render.c), at a range of sizes and settings.

Test pages

  • Text - headings, paragraphs, inline styles, quotes, pre
  • Fonts - FONT / BASEFONT sizes, faces and colours
  • Lists - UL / OL / DL / MENU / DIR, types and nesting
  • Tables - borders, spans, alignment, widths, nesting
  • Forms - inputs at various sizes, selects, textareas
  • Images - scaling, alignment, borders, ALT text
  • Links - anchors, fragments, body link colours
  • Colours - named and hex colours, backgrounds
  • CSS - selectors, font properties, borders, colours
  • Entities - named and numeric character references
  • Frames - a simple FRAMESET

This page is primarily aimed at developers, so they can see if a page renders wrongly, but also for users who want to see all the things that HighWire can do!
